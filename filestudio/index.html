Features

なぜ Omni File Studio なのか

巨大なファイルを「開く・探す・直す」ことに特化したエディターです。

⚡

数 GB でもすぐに開く

ファイル全体を読み込まないメモリマップ設計で、数 GB の CSV やログもすぐに表示が始まります。スクロールや検索も軽快です。

🔍

正規表現の検索と Grep

正規表現による検索・置換に加え、フォルダー内の複数ファイルからまとめて検索 (Grep) できます。文字コードも自動で判定します。

🔒

通信を一切しない

インターネットに接続しません。開いたファイルの内容や利用状況が外部へ送信されることはないため、業務データも安心して扱えます。

無料

無料で使える機能

テキストエディターとしての基本機能はすべて無料です。

  • ✓ 巨大ファイルの表示と編集（タブ、分割ペイン、同期スクロール）
  • ✓ 正規表現による検索・置換、複数ファイルからの検索 (Grep)
  • ✓ 文字コードの自動判定（UTF-8 / UTF-16 / Shift_JIS など）、指定し直して再読み込み
  • ✓ 文字コード・改行コードの一括変換、BOM の付け外し
  • ✓ マルチカーソル、矩形選択、元に戻す / やり直し
  • ✓ 大文字・小文字、全角・半角の変換、ブックマーク
  • ✓ ダークモード / ライトモード、最前面表示
  • ✓ エクスプローラーの右クリックメニュー「Omni File Studio で開く」（設定でオン / オフ）
Pro（月額サブスクリプション）

Pro で使える機能

アプリ内から契約でき、Microsoft アカウントの「サービスとサブスクリプション」からいつでも解約できます。

CSV

  • ✓ 表計算ソフトのような表形式表示とセルバー
  • ✓ 列の固定、オートフィルター、オートフィル、フラッシュフィル
  • ✓ ピボット集計、重複行の削除、列の分割・結合
  • ✓ セル・行・列のマーカー、スポットライト

ファイルの比較と結合

  • ✓ ファイル・タブ同士の比較
  • ✓ ファイルの結合、ログのタイムスタンプ順結合、CSV の統合
  • ✓ 結合結果から元ファイルへのジャンプ、分割出力（サイズ / トークン数）

バイナリ

  • ✓ バイナリ (Hex) 表示と上書き編集
  • ✓ データインスペクター（整数・浮動小数点・エンディアン・UNIX 時刻・GUID）
  • ✓ エントロピー・ミニマップ、バイナリ差分

その他

  • ✓ 拡張コピー（SQL の IN 句・VALUES 形式、TSV・Markdown・HTML の表形式など）
  • ✓ Base64・URL のエンコード / デコード、二分境界絞り込み (Squeeze Jump)
  • ✓ ピン留めの特殊な方式（半透明・ミニ表示・非アクティブ時に薄くする・Alt ですり抜け）
