Features

なぜ Omni File Studio なのか

巨大データの閲覧・絞り込み・整形をスムーズに行えるよう、パフォーマンスを徹底して追求しました。

⚡

スムーズにオープン（メモリマップ設計）

ファイル全体をメモリに展開しないメモリマップトアーキテクチャにより、1GB を超える CSV や TSV、ログファイルでも素早く閲覧を開始できます。

🔍

リアルタイム正規表現フィルター

複数列にまたがる AND / OR 検索、正規表現、数値範囲フィルターをバックグラウンドスレッドで高速処理。結果の行だけを瞬時に抜き出せます。

📊

列別統計＆ピボット集計

ユニーク値の頻度集計、NULL率、最小・最大・平均値をワンクリックで算出。データクレンジングや異常ログの検出が直感的に完了します。

Omni エコシステム連携

単体アプリ ＋ OmniPane Explorer プラグイン

Omni File Studio は軽量な独立ツールとして単体起動できるだけでなく、OmniPane Explorer の「プレビューペイン」または「専用タブ」としてそのままドッキング可能です。エクスプローラーから巨大ファイルをドラッグ＆ドロップするだけで即座に解析が始まります。

✓ OmniPane Explorer ユーザーは追加のランタイムなしで即座に連携可能

予定されている動作要件・仕様

対応 OS Windows 11 / Windows 10（64-bit）
対応形式 CSV, TSV, 各種区切りテキスト, サーバーログ (IIS / Apache / Nginx / JSONL)
文字コード UTF-8 (BOM有/無), UTF-16, Shift_JIS, CP932 自動判定
外部通信 ローカル動作（ファイルデータが外部サーバーへ送信されることはありません）
