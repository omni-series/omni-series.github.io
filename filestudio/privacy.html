プライバシーポリシー

最終更新日: 2026年10月25日

1. はじめに

このプライバシーポリシーは、Omni Series Project が提供する Windows 用アプリ「Omni File Studio」(以下「本アプリ」) における情報の取り扱いについて説明するものです。

2. 収集する情報

本アプリは、個人情報、利用状況、端末の情報、開いたファイルの内容を一切収集しません。本アプリはインターネットやその他のネットワークに接続する機能を持たず、データを外部へ送信することはありません。

3. PC 内に保存される情報

本アプリは、使い勝手のために次の情報をお使いの PC の中にだけ保存します。これらが外部へ送信されることはありません。

  • 環境設定 (表示、フォント、テーマなど)
  • 最近使ったファイル、開いていたタブ、検索履歴、CSV の表示状態など作業の状態

これらは通常、アプリをアンインストールすると Windows によって削除されます。

4. アプリ内購入

有料アドオン (Professional) の購入と購入済みかどうかの確認は、Microsoft Store の仕組みを通じて行われます。支払い情報は Microsoft が取り扱い、本アプリや Omni Series Project が受け取ることはありません。Microsoft による情報の取り扱いは Microsoft プライバシー ステートメント をご覧ください。

5. 第三者への提供

本アプリは情報を収集しないため、第三者へ提供する情報もありません。

6. ポリシーの変更とお問い合わせ

本ポリシーを変更する場合は、このページで更新日とともにお知らせします。ご質問は GitHub Issues までお寄せください。

Privacy Policy

Last updated: October 25, 2026

1. Introduction

This privacy policy explains how information is handled in "Omni File Studio" (the "App"), a Windows app provided by Omni Series Project.

2. Information we collect

The App does not collect any personal information, usage data, device information, or the contents of the files you open. The App has no feature that connects to the internet or any other network, and it never sends data anywhere.

3. Information stored on your PC

For convenience, the App stores the following only on your PC. It is never sent anywhere.

  • Preferences (display, fonts, theme and so on)
  • Recent files, open tabs, search history, CSV view state and similar work state

Windows normally removes this information when you uninstall the App.

4. In-app purchases

Purchases of the paid add-on (Professional) and checks of whether you own it are handled through the Microsoft Store. Payment information is handled by Microsoft and is never received by the App or Omni Series Project. See the Microsoft Privacy Statement for how Microsoft handles information.

5. Sharing with third parties

Because the App collects no information, there is nothing to share with third parties.

6. Changes and contact

If this policy changes, we will post the update on this page with a new date. Please send questions to GitHub Issues.
