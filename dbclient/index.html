シンプル＆軽量なデータベースクライアント

日々のちょっとしたクエリ実行やデータ参照を、もっと手軽に。
Omni Db Client は、必要なデータを素早く確認・編集・エクスポートすることを目指した、Windows ネイティブ設計の DB ツールです。

事前要望・フィードバックを送る ↗ Omni Series ポータルへ

Features

ストレスフリーな DB 操作を追求

Electron や重いランタイムに依存せず、Windows ネイティブならではの軽快なレスポンスを目指します。

⚡

素早い起動＆低リソース消費

バックグラウンド常駐時も OS に負担をかけにくい省リソース設計。必要なときに素早く呼び出し、スムーズにクエリを実行できる環境を目指します。

📝

スマート補完 ＆ インライン編集

テーブル名・カラム名の入力補完。グリッド上のセルを直接クリックしてインライン修正し、安全にトランザクションコミット。

📤

手軽なデータエクスポート

取得結果を CSV, TSV, JSON, SQL INSERT 文として手軽にコピー・保存。Omni File Studio と連動したデータ確認もスムーズに行えます。

対応予定のデータベース

主要な RDBMS および組み込みデータベースに順次対応します。

🐘 PostgreSQL v12〜v17 対応
🐬 MySQL / MariaDB v8.0+ / v10.5+
🪶 SQLite ローカルファイル即時参照
🏢 Microsoft SQL Server Azure SQL 含む
Omni エコシステム連携

OmniPane Explorer 内で直接クエリを実行

OmniPane Explorer の 4 ペインワークスペースに Omni Db Client を組み込むことで、ファイルツリーから SQL マイグレーションファイルを選び、隣のペインで対象 DB に対して直接実行し、実行結果をその場のエクスプローラーペインに CSV 出力するという一連のフローが 1 つのウィンドウで完結します。

✓ デスクトップの散乱やウィンドウ切り替えの手間を大幅に削減
