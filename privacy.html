プライバシーポリシー — OMNI SERIES
WinSolutions / Omni Series Project（以下「当プロジェクト」）は、提供するソフトウェア群「Omni Series」（OmniPane Explorer、Omni Warp Helm、Omni File Studio、その他関連ツール）および公式ウェブサイト（以下「本サイト」）において、ユーザーのプライバシーとデータセキュリティを最優先に尊重し、以下の通りプライバシーポリシーを定めます。

1. 基本方針（ローカル優先設計）

当プロジェクトのソフトウェアは、「ローカル優先（Local-First）・ゼロテレメトリ」を設計原則としています。業務上の機密文書や日常の操作ログをお預かりするツールであるからこそ、不要な外部クラウド通信を徹底的に排除し、すべてのデータをユーザーの手元のデバイス内に留める設計を採用しています。

2. 収集・外部送信しない情報

Omni Series ソフトウェアは、以下の情報を一切収集、蓄積、外部サーバー送信しません：

  • ファイルおよびフォルダの内容: 閲覧・編集・検索・比較したファイルデータやメタデータはすべて端末内で処理されます。
  • キーボード入力およびマウス操作ログ: マウス・キーボード共有機能（Omni Warp Helm 等）での操作データは、同一ローカルネットワーク（LAN）内の端末間でのみ直接転送され、記録や外部送信は行われません。
  • クリップボード内容および画面ミラー映像: 暗号化されて同一ネットワーク内の端末間でのみ直接送受信され、外部サーバーを経由しません。
  • 個人を特定できる情報: 氏名、住所、電話番号、位置情報等の個人情報はアプリ単体では取得しません。
  • 画面文字読み取り（OCR）データ: 標準機能では Windows 内蔵のエンジンを使用し、すべてオフライン端末内で処理されます。

3. 外部通信が発生する例外的なケース

ソフトウェアにおいて外部ネットワーク通信が発生するのは、以下の限定されたケースのみです：

  • オンライン決済およびライセンス認証: Stripe（Stripe, Inc.）または Microsoft Store を通じた有料ライセンスの購入手続きおよび定期的な有効性確認の通信（HTTPS暗号化通信）。
  • ユーザーが任意で設定した外部 API 連携: 高精度 AI OCR 等でお客様ご自身が取得した API キー（例：Google Gemini API）を設定した場合に限り、選択された画像領域のみが該当プロバイダーの公式 API サーバーへ直接 HTTPS 暗号化送信されます。当プロジェクトのサーバーを経由することはありません。

4. 通信のセキュリティと暗号化

PC 間のすべての通信（マウス・キーボード操作、クリップボード同期、画面ミラーデータ）は、高度な暗号化（AES-256）によって保護されます。通信は同一 Wi-Fi または有線 LAN 内でピア・ツー・ピア（P2P）直接行われ、第三者のサーバーを経由することはありません。

5. 公式ウェブサイトにおけるアクセス解析

本紹介ウェブサイトでは、サイトの利用状況の把握および利便性向上のため、Cookie を使用した一般的なアクセス解析ツール（Google Analytics、Microsoft Clarity 等）を利用する場合があります。取得されるデータは匿名化されており、個人を特定するものではありません。ブラウザの設定により Cookie を無効化することも可能です。

6. お問い合わせ窓口

本プライバシーポリシーに関するご質問やご不明点、個人情報の取扱いに関するご相談は、GitHub Issues または各製品のサポート窓口よりお問い合わせください。

製品ごとの詳細なプライバシー条項については、各製品ページ（OmniPane Explorer / Omni Warp Helm / Omni File Studio）もご覧ください。

MASTER PRIVACY POLICY — OMNI SERIES
WinSolutions / Omni Series Project ("we", "us", or "our") develops the "Omni Series" productivity software suite (including OmniPane Explorer, Omni Warp Helm, Omni File Studio, and related utilities) and operates this official website. We consider user privacy and data security paramount and are committed to protecting it under this Privacy Policy.

1. Core Principles (Local-First Architecture)

The Omni Series software is architected from the ground up on the principles of "Local-First" computing and zero telemetry. Because our tools are designed to interact with sensitive professional documents and daily desktop operations, we strictly eliminate unnecessary cloud dependencies and ensure all core data remains within your local custody.

2. Information We Never Collect or Upload

Omni Series applications do not collect, harvest, store, or transmit any of the following data to external servers:

  • File & Folder Contents: Files, directories, tags, metadata, notes, and search queries are processed strictly on your local PC.
  • Keystrokes & Mouse Movement Logs: Input events transmitted via software KM sharing (Omni Warp Helm) communicate strictly within your local network (LAN) and are never logged to disk or uploaded externally.
  • Clipboard Data & Screen Mirroring Video: Streamed peer-to-peer across your local area network (LAN/WLAN) with end-to-end encryption without traversing cloud intermediaries.
  • Personally Identifiable Information (PII): We do not collect names, home addresses, phone numbers, or device tracking IDs within our software applications.
  • Screen OCR Data: Default Optical Character Recognition runs completely offline on your device using native Windows OCR APIs.

3. Limited External Network Connectivity

Outbound network connections occur solely in the following specific circumstances:

  • Payment Processing & License Activation: Secure checkout and recurring subscription license validation conducted directly via Stripe (Stripe, Inc.) or Microsoft Store via encrypted HTTPS.
  • User-Configured Third-Party AI APIs: If you voluntarily configure an optional external AI provider (such as your personal Google Gemini API key for high-accuracy OCR), image snippets are sent directly and securely (HTTPS) to Google's official endpoints. Licensor never intermediates or stores such data.

4. Security & Encryption Standards

All direct peer-to-peer network communication (mouse/keyboard inputs, clipboard synchronization, and screen mirroring streams) is protected using bank-grade AES-256 symmetric encryption. Communications occur entirely within your local Wi-Fi or Ethernet network without third-party server relay.

5. Website Analytics & Cookies

Our promotional website may use standard web analytics tools (such as Google Analytics and Microsoft Clarity) with cookies to analyze aggregate visitor traffic and improve user experience. Data collected is anonymous and does not personally identify individual users. You can disable cookies at any time via your browser settings.

6. Contact & Inquiries

If you have any questions or concerns regarding this Privacy Policy, please contact us via GitHub Issues or our product support channels.

For product-specific privacy terms, please refer to OmniPane Explorer Privacy Policy and Omni Warp Helm Privacy Policy.
