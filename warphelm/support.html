Support & Guide

サポート ＆ クイックガイド

初期セットアップ手順、よくある質問、トラブルシューティングおよびお問い合わせ窓口をご案内します。

🚀 初回クイックスタートガイド（3ステップ）

1

両方の PC で起動

操作する側のパソコン（メインPC）と、操作される側のパソコン（サブPC）の両方で Omni Warp Helm を起動します。

2

ネットワーク内での自動認識

同じ Wi-Fi や有線 LAN に接続していれば、アプリが自動的にお互いを検出します。相手 PC の IP アドレスを調べる必要はありません。

3

画面配置の調整

トレイメニューの「画面レイアウト設定 (Ctrl+Alt+F11)」を開き、実際の机のモニター並び順に合わせてドラッグ＆ドロップで配置を保存します。

📱

スマホやタブレットをサブモニターにする場合 QR Code

PCのタスクトレイアイコンを右クリックして「Web サブモニター（QRコード）...」を選択し、表示されたQRコードをスマホやiPadのカメラで読み取るだけで、ブラウザが即座にワイヤレスサブモニターとして動作します。アプリのインストールは一切不要です。

❓ よくある質問とトラブルシューティング（FAQ）

Q. クライアントPCが自動検出されず、接続できません。

以下の点をご確認ください：

  • 両PCが同一のローカルネットワーク（同じルーターまたは同じWi-Fi）に接続されているか。
  • Windows Defender 等のセキュリティソフトで OmniWarpHelm.exe の通信が許可されているか。
  • Wi-Fi 接続の場合、ルーターの「プライバシーセパレーター」機能が有効になっていると端末間通信がブロックされます。
  • 手動で接続する場合は、設定画面で相手PCのIPアドレスを直接指定して接続することも可能です。

Q. 管理者権限の確認画面（「許可しますか？」ダイアログ）やサインイン画面でマウス・キーボードが動きません。

Windows の管理者確認画面やロック画面を操作するには、専用の常駐機能が必要です。サブPCのタスクトレイアイコンを右クリックし、「**管理者確認/ロック画面対応サービスをインストール**」を実行してください（Pro エディション機能）。

Q. マウスが相手PCに行ったまま、手元に戻らなくなりました。

緊急脱出ホットキーとして ScrollLock キー（または Ctrl+Alt+Esc / Pause/Break）を押してください。瞬時に手元PCへマウス操作権が強制復帰します。

Q. カーソルがどこにあるか見失いました。

キーボードの 左 Ctrl キーを素早く2回連打（ダブルタップ）してください。現在のカーソル位置にスポットライトとアニメーション波紋が表示され、広いマルチ画面から一瞬で見つけ出せます。

Q. 外部インターネットへの通信は発生しますか？

通常のマウス・キーボード共有、画面ミラー、ファイル転送、標準の文字読み取り（Windows標準エンジン）は、同一ローカルネットワーク内および端末内のみで直接通信・処理され、外部サーバーを経由しません。

※外部通信が発生するのは、(1) Microsoft Store による標準のライセンス認証、および (2) 設定で「高精度 AI OCR（Gemini API 連携）」を任意で有効にした場合の Google API への直接通信（HTTPS暗号化）のみです。開発者独自の収集サーバー等は存在せず、操作内容や個人情報が収集されることはありません。

Q. iPad やスマホを、PCのメイン作業画面を邪魔しない「完全独立サブモニター」として使えますか？

はい、Windows用の仮想ディスプレイドライバ（VDD）を導入することで可能です。
無料・オープンソースの Virtual Display Driver (IddCx) などをインストールすると、物理モニターを増設せずにPC内に「仮想的な拡張デスクトップ」を作成できます。

OmniWarpHelm は仮想ディスプレイ（\\.\DISPLAYn）を自動認識し、その仮想画面だけを手元の iPad やスマホのブラウザへ低遅延配信します。メイン画面の作業を続けながら、手元の画面で別アプリを独立してタッチ操作できます。
