# Omni Warp Helm - Product Website

Official website and documentation for **Omni Warp Helm** — Windows Native Ultra Low-Latency KM Sharing, Screen Mirroring, and Remote Direct File Edit utility.

- **URL**: [https://omni-series.github.io/warphelm/](https://omni-series.github.io/warphelm/)

## Structure

- `index.html`: Product landing page, feature highlights, and comparison table
- `editions.html`: Community (Free) vs. Pro edition pricing and detailed matrix
- `privacy.html`: Comprehensive privacy policy compliant with Microsoft Store certification
- `support.html`: 3-step quick start guide, troubleshooting FAQ, and contact links
- `assets/site.css`: Custom utility styles & animations
- `images/`: Logos, icons, and media assets
- `_config.yml`, `robots.txt`, `sitemap.xml`: SEO and GitHub Pages deployment configuration
