プライバシーポリシー

最終改定日: 2026年10月25日

1. 基本方針

Omni Warp Helm Project（以下「当プロジェクト」）は、ユーザーのプライバシーとセキュリティを最優先に設計されています。本ソフトウェアはローカルネットワーク内での直接通信を主軸とするユーティリティであり、ユーザーの個人情報や日常操作ログを当プロジェクトのサーバーへ送信・収集する機能は含まれていません。

当プロジェクトは、ユーザーが本ソフトウェアを安心してご利用いただけるよう、以下に定めるプライバシーポリシーを遵守します。

2. 収集しない情報

Omni Warp Helm は、以下の情報を収集、蓄積、外部送信しません:

  • キー入力内容およびマウス操作ログ: 接続先 PC への転送のみに用いられ、ディスクへの記録や外部送信は行われません。
  • クリップボード内容および転送ファイル: 暗号化されて同一ネットワーク内の端末間でのみやり取りされ、外部クラウド等を経由しません。
  • 個人を特定できる情報: 氏名、メールアドレス、位置情報、デバイス固有識別子等の個人情報は取得しません。
  • 画面文字読み取り（OCR）データ: 標準モードでは Windows に内蔵された認識エンジンを使用し、すべて端末内（オフライン）で処理されます。ユーザーが任意で「Google Gemini API 連携（高精度 AI OCR）」を有効にした場合に限り、選択した切り抜き画像が Google の API サーバーへ直接送信（HTTPS暗号化）されます。当プロジェクトのサーバーを経由・蓄積することはありません。

3. 通信のセキュリティと暗号化

PC 間のすべての通信（マウス・キーボード操作、クリップボード、画面ミラーデータ）は、高度な暗号化（AES-256）によって保護されます。

通信は同一ネットワーク内で直接行われ、第三者のサーバーを経由することはありません。

4. 同僚との共有（Pro）について

同僚との共有を有効にした場合に限り、次の情報を、ペアリングした同僚の PC へ送ります。

  • この PC の表示名と、ペアリング用の端末の鍵（公開鍵）
  • 利用者が選んだウィンドウの画面、または利用者が選んだファイル

画面とファイルは、受け取る側の利用者が確認画面で許可した場合にだけ送ります。通信は同じネットワーク内の PC 同士で直接行い、暗号化します。当プロジェクトや第三者のサーバーは経由せず、当プロジェクトがこれらの情報を収集・保存することはありません。

ペアリングした相手の一覧と、共有の記録（いつ、誰と、何を共有したか）は、利用者の PC の中にだけ保存します。

5. ウェブサイトにおけるアクセス解析

本紹介ウェブサイトでは、サイトの利用状況の把握および利便性向上のため、Cookie を使用した一般的なアクセス解析ツールを利用する場合があります。取得されるデータは匿名化されており、個人を特定するものではありません。ブラウザの設定により Cookie を無効化することも可能です。

6. お問い合わせ窓口

本プライバシーポリシーに関するご質問やご不明点は、GitHub リポジトリの Issues よりお問い合わせください。
